# SproutMill

เกมวางแผนสร้างฟาร์มและโรงงานบนแผนที่ช่อง ปลูกพืช เลี้ยงสัตว์ แปรรูป ขนส่ง และขายให้ทันเป้า เล่นได้ในเบราว์เซอร์ ทั้งมือถือ iPad และคอม

**เล่น:** https://clsclassic-droid.github.io/town-game/

## จุดเด่น
- **เงา เค็ม มลพิษ** ทุกช่องมีผลต่อความเร็วการผลิต ต้องวางผังให้ดี กดปุ่ม "🎨 เงา/เค็ม/มลพิษ" เพื่อดูแผนที่ผลกระทบ
- **หอเวท 3 ชนิด** ลบผลกระทบแต่ละแบบ (หอเวทสุริยะวายุ เสาคริสตัลดูดเกลือ ตะเกียงเวทสีเขียว)
- **แคมเปญ 6 ด่าน** ธีมส่งเสบียงให้กองทหาร มีเนื้อเรื่องและตัวละครประจำด่าน เล่นคนเดียว
- **โหมดแข่งกับ AI หรือเพื่อน** ใครถึงเป้าก่อนชนะ (ออนไลน์ ห้องละไม่เกิน 4 คน รวม AI)

## สถานะ
อยู่ระหว่างพัฒนา เนื้อเรื่องด่าน 1–2 มีภาพจริงแล้ว ด่าน 3–6 ยังเป็นภาพชั่วคราว
