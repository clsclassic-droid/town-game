# Town Game Online

เกมฟาร์มสร้างเมือง (แนว Town Star) โหมดแข่งออนไลน์กับเพื่อน

- เล่น: https://clsclassic-droid.github.io/town-game/
- สร้างห้อง แล้วส่งรหัสห้อง/ลิงก์ให้เพื่อน (ห้องละไม่เกิน 4 คน รวม AI)
- ต่างคนต่างสร้างเมืองของตัวเอง กติกาเดียวกัน ใครถึงเป้าก่อนชนะ
- ใช้ Supabase Realtime (broadcast + presence) ไม่มีการเก็บข้อมูลลงฐานข้อมูล
